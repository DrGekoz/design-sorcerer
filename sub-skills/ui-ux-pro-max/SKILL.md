# UI UX Pro Max sub-skill

Canonical source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Install with the canonical CLI/source workflow from the repository documentation. Preferred project-local installation:

```bash
npx ui-ux-pro-max-cli install --scope=project
```

If the CLI is unavailable, use the repository’s documented `npx skills add` command rather than copying an unverified bundle. Load this sub-skill for design-system exploration, style selection, color palettes, typography pairings, UX guidelines, and chart recommendations. Reconcile its output with `DESIGN.md`, existing product constraints, accessibility, and the parent skill’s free-first rules.
