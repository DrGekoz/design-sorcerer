# Impeccable sub-skill

Canonical source: https://github.com/pbakaus/impeccable

Install from the project root with:

```bash
npx impeccable install --scope=project
npx impeccable init
```

Use `/impeccable critique`, `/impeccable polish`, `/impeccable audit`, `/impeccable harden`, `/impeccable optimize`, `/impeccable document`, and `/impeccable live` at the phases described by the parent Design Sorcerer skill.

This wrapper intentionally points to the canonical installer instead of vendoring a generated provider bundle.
